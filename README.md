Mi enfoque es el desarrollo **Full Stack**, con aplicaciones web y móviles, servicios backend y bases de datos relacionales.

- **Web y móvil:** interfaces con React y aplicaciones con React Native.
- **Backend:** desarrollo de servicios y APIs REST con Node.js y Express.

- **Desarrollo:** JavaScript, Java y Python.
